# NARAKA三模型协作规范

状态：2026-09-02已确认并补充逐模块UI交付规则
目标：让DeepSeek提供代码草案与Unity手工操作说明，Claude负责实际仓库中的代码复核、功能实现和缺陷修复，Codex负责跨模块集成、架构门禁、CI、服务端与部署校验。

## 1. 权威来源顺序

1. 用户当前明确指令。
2. 项目根目录五份`NARAKA_*.md`权威文档及已接受ADR；以用户指定的Markdown 2.1纠错规则为最高优先级，其中纠错结论优先于旧版GDD、TDD和任务表。
3. 当前Git仓库中的源码、配置和可重复测试结果。
4. 仅在本轮涉及玩法、完整架构或任务表冲突时读取`outputs/naraka_design_v2/`。
5. DeepSeek、Claude和Codex的自然语言或代码输出都只是候选变更，未进入仓库并通过验证前不构成项目事实。

任何模型都不得把旧对话记忆当作事实来源，不得重新设计已经确认的玩法。

## 2. 职责划分

### DeepSeek：草案与手工UI指导

- 不假定能够读取仓库、运行Unity、修改文件或执行测试。
- 根据用户粘贴的最小必要上下文生成C#草案、Unity层级结构、组件参数和挂载步骤。
- 主要服务于UI View、界面层级、Inspector配置、Prefab/UIDocument绑定和表现逻辑。
- 必须明确列出假设、所需文件、建议改动路径和未验证事项，不得宣称“已运行”或“已通过”。
- 不修改玩法、服务端权威规则、数据库、协议或`LegacyNetworkV1`。
- 网页版DeepSeek每轮只接收一个完整文字任务，不得期待它自动读取上轮仓库状态。每份任务必须重复写明项目基线、当前已完成事实、现有接口摘要、本轮唯一目标、输出格式、手工步骤、明确排除项和验收标准。
- DeepSeek完成一个模块后必须停止。只有用户完成手工操作、Claude在真实仓库中复核运行、Codex完成集成门禁后，Codex才生成下一模块的全新文字任务；不能让DeepSeek自行推导或连续开发后续页面。

### Claude：仓库内复核、实现与调试

- 开始前读取当前Git状态、五份权威文档、相关ADR和实际目标文件。
- 对DeepSeek草案进行代码审查；不因草案看似完整就直接采用。
- 在用户授权的范围内实现或修复代码，运行相关Unity或.NET测试，检查Console、日志和实际功能。
- 负责命名、生命周期、取消、订阅释放、MVC依赖方向和Unity序列化/挂载正确性。
- 发现架构或玩法冲突时停止扩展并向用户报告，不能自行改变基线。

### Codex：集成与架构守门

- 负责跨客户端/服务端边界、模块依赖、CI、数据库迁移、部署与最终一致性检查。
- 复核Claude的实现证据与Git差异，在必要时解决跨模块缺陷。
- 同步权威文档和ADR，确保实现、测试、运维记录与当前阶段一致。
- 每项用户需求完成后暂停，在得到用户许可后才开始下一项开发。

## 3. 单写入者规则

- 同一时间只有一个模型可以修改同一工作区或同一组文件。
- DeepSeek只输出草案；用户手工操作Unity期间，Claude和Codex不并行编辑对应场景、Prefab、UXML、USS或脚本。
- Claude完成一轮后必须提供Git状态、变更文件、实际测试和遗留问题，Codex再接手复核。
- Codex接手后如需修改Claude刚处理的文件，先说明原因和范围；不得用重置、覆盖或大规模格式化消除未审阅改动。
- 每次交接都以当前磁盘和Git差异为准，不以聊天中粘贴的旧版本代码为准。

## 4. 推荐交付流程

1. 用户指定一个清晰、可验收的功能或UI页面。
2. Codex或Claude从权威文档提取固定边界和验收标准。
3. 需要视觉搭建时，用户把必要上下文交给DeepSeek，获得代码草案和逐步挂载说明。
4. 用户在Unity中手工创建或挂载UI，并保存场景、Prefab或UI Toolkit资产。
5. Claude读取实际仓库，复核并修正草案与挂载，运行功能和测试。
6. Codex检查模块边界、跨端契约、CI和文档；确认完成后向用户请求下一项许可。

第一轮UI任务固定为“正式登录界面View升级”，不得把P0已有账号、版本预检、网络或空大厅业务重新实现。具体可复制任务见`Docs/AI/DEEPSEEK_UI_PROMPT.md`。Claude在用户完成草案或手工挂载后按`Docs/AI/CLAUDE_PROJECT_PROMPT.md`复核实际磁盘；如果磁盘中尚无草案，也只能在同一登录View范围内补齐最小实现。

## 5. 每轮交接清单

- 目标和明确排除项。
- 修改过的绝对或仓库相对路径。
- Unity场景、Prefab、UXML/USS、Inspector和脚本挂载变化。
- 实际运行过的命令、测试数量和失败/跳过数。
- 尚未验证的人工步骤。
- Git状态以及是否包含用户原有改动。
- 不包含密码、连接串、令牌、私钥、`.env`内容或数据库导出。

可直接复制的模型提示词：

- `Docs/AI/CLAUDE_PROJECT_PROMPT.md`
- `Docs/AI/DEEPSEEK_UI_PROMPT.md`
