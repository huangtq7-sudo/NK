## Unity 人工操作清单

1. 本地 SSH 隧道保持停止，确保 5222/8011 由本机验收 Host 占用。
2. 打开正式工程 `E:\NK项目\NK` 的 `Assets/Scenes/SampleScene.unity`，进入 Play。
3. 使用本机开发库账号登录；云端账号不会自动存在于本机库，需要时自行注册测试账号。
4. 从大厅点击开始游戏，确认加载界面连续显示并进入正式 `Map01_Task`。
5. 经固定传送门进入正式 `Map02_Combat`，确认角色、相机、战斗与 HUD 正常。
6. 在战斗中死亡，确认成功返回地图一重生点，远征继续有效。
7. 从地图一返回大厅，确认加载完成、大厅恢复且没有重复玩家或重复账号资产。
8. 在一次活动远征中退出 Play，再重新 Play/登录，确认正常回到大厅并能开始新的远征。
9. Console 不出现未处理异常或已释放状态写入错误。

如尚无“返回大厅”按钮，请用户在地图一手工绑定场景 `WorldSceneEntry` 组件的
`RequestReturnToLobby` 方法；自动化工具不得创建或覆盖用户布局。

P3 当前没有正式怪物掉落生产链路和新掉落数值。Unity 人工流程中临时战利品为空
不等于结算失败；真实掉落/资产清理的验证由上述受信服务端夹具覆盖，内容扩充按 P4 执行。
