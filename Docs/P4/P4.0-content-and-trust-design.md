## 3. 任务与对话模型

状态链：`Locked → Available → Accepted → InProgress → ReadyToSubmit → RewardPending → Claimed`。Locked/Available 由服务端按配置、前置任务（必须已领取）、账号等级与上限推导，不落库；落库实例只会单向前进。主线同时 1 条进行中，支线最多 5 条；待领取仍占名额。重复悬赏的实例键规划为 `QuestId@ServerDay`，当前编译器拒绝 `RepeatRule` 为 `None` 以外的值。

| 层 | 客户端 | 服务端 |
|---|---|---|
| Model/Domain | `Quest.Model`（服务端日志快照）、`Dialogue.Model`（`DialogueSession` 揭示规则） | `Domain.Quests`（`QuestLog` 账号级聚合、`QuestInstance`） |
| Controller/Application | `QuestController`（AppRoot，跨场景）、`QuestConversationPlanner`、`NpcInteractionController`、`DialogueController`、`PlayerGameplayInputLock`（地图 Scope） | `QuestService`、`QuestRequestThrottle`、`ExpeditionQuestProbe` |
| View/Infrastructure | `NpcInteractionVolume`、`InteractPromptView`、`QuestTrackerView`、`QuestRewardPanelView`、`DialogueBoxView`；`LegacyNetworkAdapter.Quest` | `SqlSugarQuestRepository`；协议 67/68 |

交互规则：E 仅在玩家存活、无动作/受击、未锁输入、无其他面板时生效；重叠范围取水平距离最近者，新候选需近 0.3 m 才切换，距离相同按 NpcId；离开范围、死亡、场景卸载、断线取消对话且不推进任务。一次左键按下只做一件事：逐字中揭示本句，已揭示时进入下一句，末句揭示后结束；Esc 关闭（不算读完）。对话期间锁定角色输入、不改 `Time.timeScale`；关闭对话后等左键松开才归还输入，避免关闭的那一下变成攻击。主线对话目标类别为 `Dialogue`，不产生成就来源事件，不计入未来大厅“战斗任务”（仅统计 `Combat` 类别）。

对话选择优先级：可复命→提交对话；是当前对话目标→目标对话；奖励待领取→待领取提示后打开领取面板；可接取→接取对话；进行中→进行中提示；其余→日常对话。读完接取对话最后一句才发出接取意图。

## 4. 服务端信任边界（P4.1 已实现）

协议 `MsgQuestRequest=67`/`MsgQuestResponse=68`，能力 `quest`。请求只有 RequestId、操作、QuestId、ObjectiveId、DialogueId；没有账号、奖励、数量或经验。

| 操作 | 校验 |
|---|---|
| GetJournal | 认证；每账号 0.5 s 读限流 |
| Accept | 任务启用；接取对话匹配；活动远征；前置已领取；等级；上限 |
| CompleteDialogue | 当前顺序目标；Talk 且已启用；对话匹配；活动远征；距该步骤开始 ≥ MinCompletionSeconds |
| Submit | ReadyToSubmit；提交对话匹配；活动远征；≥ SubmitMinSeconds |
| Claim | RewardPending；不要求远征 |

领取事务（一次事务）：锁 `account_progression` → `account_profile`（与远征结算同序）→ 重建日志并判定 → 写 `account_reward_claims`（`Quest`, 实例键，换 RequestId 也只能一次）→ 物品入仓（放不下则整体回滚，保持待领取）→ 货币与 `currency_ledger(QuestReward)` → `account_xp` 与 `account_xp_ledger`（封顶满级经验）→ 同步 `account_progression.account_level` → `idempotency_records`（同 RequestId 重放首次结果）。任务奖励直接进账号，不进远征临时背包，死亡不影响，与远征结算无竞态。

诚实的限制：服务端不知道玩家位置与当前地图。对话目标是“客户端声称读完 + 服务端核对顺序、对话归属、活动远征、最短时长与频率”，只适用于低价值、一次性、不可刷的对话目标。战斗类目标在 ADR-0024 落地前由配置编译器禁止启用。

资源预算：配置数 KB；不新增服务、缓存或线程；每条任务约 4 次短事务；每账号写 0.2 s、读 0.5 s 限流，限流表上限 1024 条并清理过期项；日志不记令牌与连接串。

门禁：本机验收用隔离端口 Host，保持 `p3-config-1` 只追加 `quest` 能力；P4 客户端连 P3 云端时拿不到 `quest`，任务入口静默、只能播日常对白，不发送 67。正式 P4 发布时再统一提升门禁。

## 6. 红点

地图内的 NPC 头顶标记是任务展示状态，不进红点系统（同在线绿点的处理原则）。大厅目前没有任务入口，P4.1 不新增任务红点节点，避免出现无法清除的红点；任务经验升级后，既有 `Lobby/AccountLevel/ClaimableReward` 由等级奖励规则自然点亮。大厅任务日志界面出现时再登记 `Lobby/Quest/*` 节点。
