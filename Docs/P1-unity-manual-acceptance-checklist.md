## 2. 结果填写规则

每项使用以下结果之一：

- `通过`：表现与预期一致，Console没有新增异常。
- `失败`：功能不可用、布局明显错误、状态错误或出现异常。
- `受阻`：当前云端不支持、缺少两个测试账号、缺少对应数据或素材。
- `不适用`：当前阶段明确不要求。

发现问题时至少记录：界面、操作步骤、预期结果、实际结果、是否稳定复现、Console第一条异常。截图前必须确认画面没有密码或其他敏感信息。
